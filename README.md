# McKeldin-Plant-Patent-Project
Repository for Plant Patent Project code produced by the University of Maryland's McKeldin Library GIS and Data Services Team.

The goal of this project is to create a map showing US-patented plants across the world, and to update the UMD database supplying this information using USPTO API metadata.

Files:
metadata_needed.csv -- metadata included in the UMD database matched with metadata available in the USPTO API
